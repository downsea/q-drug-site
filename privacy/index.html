Privacy Policy

Last updated: 2026-09-14

This policy covers the personal command-line tool operated by the owner of this domain ("the Tool"). The Tool is used by a single individual, on that individual's own machines, to work with that individual's own Google account.

1. What the Tool accesses

With the account owner's explicit consent, the Tool uses Google OAuth 2.0 to access the owner's Gmail account through the Gmail API. Depending on the authorization granted, this may include:

  • listing, searching, reading and downloading the owner's messages, threads and attachments;
  • sending, replying to, forwarding, drafting and archiving messages;
  • reading and modifying labels, and managing Gmail filters and settings;
  • basic profile information (email address, name) to identify the account.

2. Where the data goes

Mail content is processed locally on the owner's own devices. It is not transmitted to, stored by, or shared with any third-party server operated by us. There is no analytics, no telemetry, and no advertising. The only parties involved are the owner's device and Google's own APIs, which are contacted directly.

3. What is stored, and for how long

The Tool stores OAuth client credentials and a refresh token locally, using the operating system's keyring or an encrypted file, with file permissions restricted to the owner's account. No mailbox content is retained beyond the life of a command, except files the owner explicitly saves. Tokens can be revoked at any time (see §5), after which the stored credentials become useless.

4. Sharing

No user data is sold, rented, or shared with third parties. Data is not used for advertising or for training machine-learning models. Data is not transferred to anyone except as strictly required to operate the Tool for the owner, or where required by law.

5. Revoking access

The owner can revoke the Tool's access at any time at myaccount.google.com/permissions, or by deleting the locally stored credentials. Revocation takes effect immediately.

6. Google API Services User Data Policy

The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
